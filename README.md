# 🚀 Interactive Web Dashboard

## 📌 Project Description

Interactive Web Dashboard is a modern and responsive frontend project developed using HTML, CSS, and JavaScript. This project demonstrates JavaScript DOM manipulation and user interaction through multiple dynamic web elements.

The dashboard allows users to interact with different components such as theme controls, text customization, random generators, counters, image gallery, and many other interactive features.

---

## ✨ Features

### 🎨 Theme Controls
- Dark / Light Mode Toggle
- Random Background Color Changer
- Text Color Changer
- Reset Style Option

### 📝 Text Features
- Dynamic Heading Changer
- Motivational Quote Generator
- Current Date & Time Display
- Emoji Mood Changer

### 🔤 Font Controls
- Increase Font Size
- Decrease Font Size

### 🎲 Interactive Features
- Random Number Generator
- Counter with Increase, Decrease, and Reset Functions

### 🖼 Image Gallery
- Previous and Next Image Slider
- Image Zoom In & Zoom Out

### 🔔 Additional Features
- Welcome Alert Message
- Button Click Sound Effect
